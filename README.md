# WBSuporte DNS

Servidor DNS recursivo baseado em **Unbound**, executando em Docker.

Projeto desenvolvido para uso em infraestrutura de provedores, com foco em:

- Alta performance
- Privacidade
- DNSSEC Validation
- Hyperlocal Root Zone
- Cache otimizado
- Controle de acesso por rede
- Fácil implantação via Docker Compose


## Recursos

✅ Unbound 1.22  
✅ DNS Recursivo completo  
✅ Validação DNSSEC  
✅ Root Zone Hyperlocal  
✅ Cache otimizado  
✅ Controle de clientes permitidos  
✅ Docker Compose  
✅ Healthcheck  
✅ Remote Control via unbound-control
